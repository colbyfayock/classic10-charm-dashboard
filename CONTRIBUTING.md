# Contributing

Contributions are welcome when they improve the tested Classic10 Charm dashboard path, documentation, host tools, compatibility, or safety.

## Before opening a pull request

- Remove serial numbers, network addresses, Wi-Fi details, credentials, tokens, account information, whole-disk hashes, dumps, backups, and vendor APKs.
- State which model, firmware build, Android version, and host operating system were tested.
- Separate direct observations from assumptions.
- State whether a result came from one unit or multiple units.
- Include tests for host tools and non-trivial dashboard or kiosk behavior.
- Explain any device write, its safeguards, readback verification, and undo path.

Do not submit a write procedure that relies on a different partition layout, firmware hash, or device identity without explicit compatibility checks.
